# 按体裁组织论证

先识别文本承担的功能。下列结构用于检查信息是否齐全，具体标题和顺序服从任务模板；无需把全部栏目追加到每篇稿件。

## 开题报告

| 部分 | 需要回答 | 常见修订 |
|---|---|---|
| 背景 | 哪个现象或任务存在具体困难？为什么值得研究？ | 用任务条件和已知限制替换宏观趋势套语 |
| 研究现状 | 已有工作解决了什么？在哪些条件下仍不足？ | 按问题或方法比较，分别归属贡献 |
| 研究目标 | 拟得到什么结果？用于回答什么问题？ | 明确对象与可检验产出，不预设效果 |
| 研究内容 | 为达到目标要完成哪些研究任务？ | 每项交代问题、做法、输出及其依赖 |
| 关键问题 | 路线在哪一步存在尚需解决的困难？ | 说明难点的来源及判定条件 |
| 技术路线 | 数据如何进入方法，输出如何参与验证？ | 解释实际处理关系，避免只罗列模型名 |
| 已有基础 | 哪些工作有实物或记录支持？ | 区分资料准备、流程测试、复现和研究结果 |
| 计划 | 何时交付什么，如何判断完成？ | 用阶段产物和检验条件代替“深入研究” |

研究目标描述要达到的状态；研究内容描述完成目标需要开展的工作；关键问题描述影响路线成立的困难。三部分可以围绕同一主线，但不能只是将同一句话换动词重复三次。

“拟研究”“将比较”符合开题体裁，不必为避免重复而改成表示已完成的词。拟创新点应落在与已有方法可比较的差异上，首创性和效果结论需另有证据。

## 文献综述

围绕问题建立比较关系。每组文献可记录：研究对象、输入与假设、主要方法、评价条件、实际贡献、限制以及对当前问题的影响。

不要把每篇摘要压成一句再串联；也不要为突出选题而将已有工作整体描述为无效。若两项方法针对不同任务、数据或计算预算，应先说明不可直接比较的条件。

研究空白应具体到缺少的对象、验证环节或适用范围。检索覆盖不足时，可以说明已审阅工作尚未回答的问题，避免推断整个领域“尚无研究”。

## 论文引言与方法

引言要让读者理解问题、现有路线的限制、本文研究及其贡献。无需把一套固定修辞结构重复到每段。贡献必须能在正文中找到对应方法、结果或分析。

方法应交代能改变结果的设计选择：数据与划分、预处理、输入输出、模型或算法、训练与推断条件、对照、评价指标。阈值、预算和随机性如果影响结论，就属于方法信息；删除它们可能损害可复现性。

用一个依赖关系检查方法段：前一步的输出是什么，后一步如何使用，最后通过什么观察评价。对并行任务不必强造因果链。

## 结果与讨论

结果优先报告观察、比较和不确定性；讨论解释这些观察与研究问题的关系，以及可能机制和适用条件。两部分可按投稿体裁合并，但应能辨认观察与解释。

没有统计检验时，不把日常用法的“明显”改成技术含义的“显著”。数值差异应保留方向、单位、样本、汇总方式和必要不确定性。未提供数字时使用编辑缺项说明，不自行填入合理数值。

讨论中的机制判断需要匹配实验设计。共同变化的因素不能靠措辞排除；消融实验也需要说明保持不变的条件。证据仅支持相关关系时，保留这一范围。

## 答辩讲稿

讲稿应对应实际幻灯片，而非另写一份与原页不同的报告。每页说明它在整体研究中承担的作用，交代图表或研究内容，再自然连接下一页。

口头表达可以减少长定语和缩写密度，保持正式、完整的句子。无需逐字念完参考文献和图例，也不能省去改变结论的限制。介绍已完成工作时只说记录支持的进展；后续工作明确使用计划语气。

用户要求原页后插入稿件页时，保持一页幻灯片对应一页讲稿。若某页信息不足以写准确讲稿，先依据现有信息写清可确认内容，将缺项放交付说明。

## 局部编辑与重构的分界

“润色”“内容小改”通常不足以授权更换研究路线、标题体系、图表形式或整套主题。先用最小修改解决已发现问题。只有原结构无法承载已授权内容时，再说明需要调整的具体部分。

同一模板的栏目安排、编号样式、签名栏等是文档约束；某次任务的单条引用偏好、字数或段落数是任务参数。不要把局部偏好总结为全学科规则。
