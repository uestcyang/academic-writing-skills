# 中文学术写作

以读者能准确理解研究对象、方法和证据为目标。表达修改必须保留科学含义；未提供的结果、文献和完成记录不得补写为事实。

## 先确认任务

从当前要求及已有材料识别体裁、读者、事实依据、修改范围和交付格式。已有答案直接沿用，不让用户重复提供。缺少关键证据时先完成不依赖它的修改，集中列出真正影响结论的缺项。

将修改范围分为：

- 句内编辑：表达和语法，保持原结构与信息。
- 内容修订：允许调整论证顺序、删除冗余或重组段落。
- 版式编辑：只在明确请求或修复实际排版问题时进行。

用户指定的原稿、模板及最新研究路线优先。参考材料可用于判断栏目和组织方式，其人名、题目、研究结果与完成进度不得迁入当前稿件。

- 空话、模板句或术语堆叠：读 [patterns.md](references/patterns.md)。

只加载相关参考。纯文字润色无需检查整个项目的工具链或重建文档。

## 编辑次序

### 1. 保留事实与限制

识别研究对象、输入输出、已有结果、拟开展任务、推测、数值及单位、否定与边界条件。区分材料直接提供的信息、来源支持的信息和编辑者推断。

已有工作应按实际证据表述。环境配置、流程测试、公开实验复现和新研究结论分别对应不同进展，不能相互替代。对研究结果有影响的失败、负结果、数据划分和不可比条件应保留。

### 2. 理清论证

找出每节要回答的问题，以及每段的中心主张。按对象、条件、操作、观察与解释之间的关系组织文本；各句接续上句已引入的信息。方法中保留使同行理解设计和复现实验所需的细节。

开题说明拟解决的问题、已有方法的具体不足、拟采取的路线和可检验产出。选择与研究问题相关的代表性文献，同时保留会改变结论的重要反证，避免只引用有利材料。

不要机械套用三点结构、固定句长或每段同样的起承转合。原句逻辑完整时，避免把因果和目的关系拆成几个失去连接的短句。

### 3. 修改表达

对疑似模板句判断：删除后会损失什么事实、推论或必要限定？

- 没有损失：删除，或并入已有陈述。
- 有实质信息：保留信息，用准确的对象、条件、动作与关系改写。
- 证据不足：缩小结论或将缺项列入编辑说明，不替作者制造依据。

表达匹配仅触发检查。真实的比较、否定、统计显著性、顺序和学科惯用术语可以保留。优先保持同一对象的术语一致；不为词汇多样性轮流更换名称。

避免为了“自然”添加比喻、设问、俚语、个人感叹或宣传式评价。读者不需要了解的编辑操作、工具调用、自证说明和任务记录留在交付说明中。

### 4. 核对引文和文件

引文应支持附近的具体论断。多篇论文的贡献分别归属；仅查到题名或摘要时，明确核验范围。调整编号后继续保持论文身份、正文引用与参考文献条目的对应。

内容微调时保留标题层级、图表、样式与模板栏目。文件经过编辑或导出后检查实际渲染。没看过渲染结果，不声称格式保持、字体正确或没有遮挡。

## 最小验收

针对改动检查一次：

1. 研究对象、术语、数字、单位、否定与限定是否完整？
2. 研究进度与结论强度是否有相应证据？
3. 比较基线、因果方向和文献归属是否正确？
4. 段落是否推进论证，读者能否识别问题、方法和结果？
5. 是否符合体裁及用户允许的修改范围？

仅当发现具体风险或任务要求时扩大检查。通过几个案例或减少词表命中，不构成学术质量、人工读者效果或检测通过率的证明。

## 交付

按用户要求给出可直接使用的正文或文件。影响研究含义、证据强度或结构的修改单独简要说明；未解决的证据缺项集中列出。无须逐条解释普通语法修改，也不要把编辑说明混进正式稿。

如果用户只问一个概念或某页内容，回答该问题；不自动重写整篇论文。若用户要求保持原版并补充讲稿，逐页对应讲述，按原页内容标明已完成和拟开展工作。
