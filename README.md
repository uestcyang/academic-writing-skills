# Academic Writing Skills

面向中文学术写作的 AI 编辑技能：把研究问题、方法、证据和结论写清楚，减少空话与模板化表达，保留专业术语、必要限定和原有文档格式。

适用于开题报告、文献综述、论文正文和答辩讲稿。核心交付是一个可直接阅读或由 Agent 加载的 Markdown skill，无运行服务、API 密钥或额外依赖。

## 解决什么问题

论文润色容易在表达变流畅的同时丢失事实：把计划写成成果，把相关性写成因果，把不同文献的贡献合并，把精确术语换成模糊近义词。通用文案的口语化、设问和“增加个性”也不一定适合学术文本。

本项目按以下顺序编辑：

1. 确认研究主张与已有证据相符。
2. 理清章节功能、段落关系和方法依赖。
3. 删除无信息的句子，补足对象、条件和比较关系。
4. 核对引文归属、术语一致性和文档格式。

例如，在**仅完成环境配置和两组流程测试**的教学设定中：

> 原句：目前已完成系统验证，充分证明了方法的有效性。
>
> 修订：目前已完成实验环境配置及两组流程测试，确认输入、执行和结果记录环节能够运行。方法效果将通过后续对照实验评价。

修订纠正了研究进度和结论的关系。仅替换“充分”“有效性”等词无法解决这个问题。

## 快速使用

### 在对话中使用

提供原文、已有证据和修改范围，让助手读取 [SKILL.md](skills/academic-writing/SKILL.md)。按任务需要继续读取其中链接的参考文件。

可直接使用下面的任务说明：

```text
请按 academic-writing 修订以下开题报告正文。
读者：本学科导师。
允许：句内改写、删去无信息句、修复逻辑关系。
保持：研究路线、标题层级、术语、引文对应和模板版式。
进度与证据：以我提供的记录为准；不足之处单独列出，不补造结果。
输出：修订正文，以及会影响研究含义的修改说明。
```

### 在支持本地 skill 的 Agent 中使用

克隆本仓库，将 `skills/academic-writing/` 整个目录放入该 Agent 文档规定的技能目录。不同产品的目录和加载方式不同，本仓库不提供统一安装脚本。也可以直接让 Agent 读取文件，无需安装。

仓库不安装到用户环境、不访问外部服务，也不自动上传论文。引文核验和文件编辑使用所在环境已经授权的工具。

## 设计原则

- **先判断命题，再改表达。** 句子缺少事实和关系时，先补依据或删去空句。
- **规则服从语境。** “显著”“不是……而是……”“首先”等词可以有准确用途，命中表达不自动构成错误。
- **保持学术体裁。** 不以俚语、比喻、个人感叹或刻意打乱句长增加所谓人味。
- **保护证据边界。** 不改变数字、否定、统计结论、因果方向、研究完成度和文献归属。
- **尊重编辑范围。** 文字微调遵守原章节与样式；新增讲稿不构成重做幻灯片的授权。

## 适用边界与验证状态

这些规则是编辑启发式，未经过同学科配对语料统计、导师盲评或大规模跨模型实验。项目不输出“AI 概率”，不承诺通过检测，也不从词语命中数量推断作者身份。

仓库提供可复查的功能案例，重点检查事实保存、必要限定、因果关系、体裁和改动范围。具体执行记录见 [验收说明](evals/README.md)。这些检查不能证明投稿结果或整体写作质量提升。
